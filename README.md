As the description states, this is very much a heavy work-in-progress and is bounds to have bugs and glitches. It is already possible to view existing islands from LBA2, given you feed the right files to the program - you will have to use the LBA Package Manager; which I believe you can find here on Github as well as the magicball.net - the official fan site for the LBA series. If for some reason you are having trouble building, try setting the Visual Studio solution to x86 and Debug modes respectively.
